# souhridm.github.io

Personal site of Souhrid Mukherjee, PhD, served by GitHub Pages at https://souhridm.github.io/.

One static page (`index.html`) with inline CSS and no build step. Fonts are Geist and Geist Mono from Google Fonts. Light and dark themes follow the visitor's system setting.

To preview locally:

    python3 -m http.server 8099

then open http://localhost:8099.
